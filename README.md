# Waypoint Compass 2.0

A client-side Minecraft Fabric mod that displays your saved waypoints on an in-game HUD compass, making it easier to navigate and keep track of important locations.

**This repository is a community-maintained continuation of the original Waypoint Compass mod, with updates and improvements for newer Minecraft versions.**

## Features

- **HUD Compass:** Displays nearby waypoints directly on your screen.
- **Waypoint Management:** Create and manage custom waypoints in-game.
- **Custom Names:** Give your waypoints meaningful names.
- **Custom Icons:** Choose from multiple waypoint icons.
- **Custom Colors:** Distinguish locations using different colors.
- **Distance Display:** See how far away each waypoint is.
- **Dimension Awareness:** Waypoints are associated with their respective Minecraft dimensions.
- **Visibility Controls:** Toggle individual waypoint visibility.
- **HUD Toggle:** Show or hide the compass whenever needed.
- **Persistent Waypoints:** Your saved waypoints are retained between game sessions.

## Keybindings

The default keybindings are:

| Key | Action |
|:---:|---|
| `N` | Create a new waypoint |
| `M` | Open the waypoint menu |
| `H` | Toggle HUD visibility |

All keybindings can be changed through **Options → Controls → Key Binds**.

## Requirements

- Minecraft **26.3**
- Fabric Loader
- Fabric API
- Java 25 or newer

Make sure you install the versions of Fabric Loader and Fabric API compatible with your Minecraft version.

## Installation

1. Install Fabric Loader for Minecraft 26.3.
2. Install the compatible Fabric API version.
3. Download the latest Waypoint Compass 2.0 release from the [Releases page](https://github.com/JHONNYCODER/WaypointCompass-2.0/releases).
4. Place the downloaded `.jar` file inside your Minecraft `mods` folder.
5. Launch Minecraft using your Fabric profile.

The mod is client-side and does not require installation on a multiplayer server.

## Compatibility

This project targets Minecraft 26.3 using the Fabric mod loader.

Compatibility with other Minecraft versions is not guaranteed. Check the release notes before installing an update.
